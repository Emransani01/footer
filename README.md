# Contact & Footer Section

A simple contact and footer section built with HTML and CSS. The project includes contact information, social media links, and a message form with a clean two-column layout.

## ✨ Features

- Contact information section
- Social media icons
- Contact/message form
- Name and email input fields
- Message textarea
- Submit button
- Clean two-column layout
- Custom CSS styling
- Google Fonts integration

## 🛠️ Technologies

- HTML5
- CSS3
- Google Fonts
